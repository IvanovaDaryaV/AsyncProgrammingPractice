# Блок 1
## Задание 1
Реализован класс-обертка для работы с классом `Thread`. 

Класс-обертка позволяет выполнять делегат `Action<object>` в потоке, созданном с помощью класса `Thread`. Метод `Start()` вызывает делегат `Action<object>` в отдельном потоке `Thread`. Метод `Wait` блокирует вызвавший его поток до завершения работы делегата.

## Задание 2
Реализован обобщённый класс-обёртка `ThreadWrapper<TResult>` для работы с классом `Thread`.

Класс-обёртка позволяет выполнять делегат `Func<object, TResult>` в потоке, созданном с помощью класса `Thread`. Добавлено свойство `Result`, которое возвращает результат выполнения делегата во вторичном потоке (блокирует вызвавший его поток до окончания вычислений, либо выбрасывает сохранённое исключение в случае ошибки).

# Блок 2
## Задание 1
Реализован запуск метода в контексте задачи с использованием класса `Task`.

Метод `WriteChar` выводит переданный символ в консоль в цикле из 160 итераций с задержкой в 500 мс. Метод обёрнут в асинхронный вызов `WriteCharAsync` с помощью `Task.Run`, что позволяет выполнять его в фоновой задаче параллельно с работой основного потока.

## Задание 2
Реализована асинхронная сортировка массива с обработкой результата через продолжение задачи (`ContinueWith`).

Метод `SortArray` выполняет сортировку переданного массива целых чисел по возрастанию или убыванию в зависимости от флага `isAscending`. Метод запускается в контексте задачи с помощью `Task.Run`. Результат сортировки большого массива обрабатывается в задаче-продолжении (`ContinueWith`), где отсортированные элементы выводятся в консоль через запятую.

## Задание 3
Реализовано вычисление числа Фибоначчи в отдельном потоке с флагом `TaskCreationOptions.LongRunning` и обработкой результата через продолжение задачи.

Метод `FindLastFibonacciNumber` находит число Фибоначчи с использованием ресурсоёмкой рекурсивной функции. Для предотвращения блокировки рабочих потоков из пула потоков (`ThreadPool`) вычисление запускается с помощью `Task.Factory.StartNew` с флагом `TaskCreationOptions.LongRunning`, выделяющим отдельный поток ОС. Результат асинхронной задачи выводится в консоль с помощью задачи-продолжения (`ContinueWith`).

# Блок 3
## Задание 1
Реализован собственный планировщик задач `StackTaskScheduler`, работающий по принципу LIFO («последним пришёл — первым вышел»).

Класс `StackTaskScheduler` унаследован от `TaskScheduler` и использует потокобезопасную работу с коллекцией `Stack<Task>` для хранения запланированных задач. При постановке задачи в очередь (`QueueTask`) она добавляется в стек, после чего через `ThreadPool.QueueUserWorkItem` запрашивается рабочий поток из пула, который извлекает задачу с вершины стека и выполняет её с помощью `TryExecuteTask`. В консольном приложении создаются 40 задач, подтверждающих параллельное выполнение и порядок LIFO.

## Задание 2
Реализован собственный планировщик задач `DelayTaskScheduler`, запускающий задачи с фиксированной задержкой в 2 секунды.

Класс `DelayTaskScheduler` унаследован от `TaskScheduler`. При постановке задачи на выполнение (`QueueTask`) она сохраняется в очереди, а её исполнение откладывается на 2 секунды с помощью класса `System.Threading.Timer`. По истечении времени коллбэк таймера в потоке пула извлекает задачу и выполняет её с помощью метода `TryExecuteTask`. Метод `TryExecuteTaskInline` возвращает `false`, предотвращая синхронное выполнение задачи в вызывающем потоке. В консольном приложении демонстрируется работа планировщика: пока задача ожидает запуска и выполняется, основной поток выводит индикатор прогресса (символы `*`) с шагом 100 мс, после чего задача выводит идентификатор потока и признак принадлежности к пулу потоков (`IsThreadPoolThread`).

# Блок 4
## Задание 1
Реализован асинхронный запуск вычисления факториала без блокировки основного потока выполнения.

Метод `CalculateFactorial` вычисляет факториал числа с использованием типа `BigInteger` для предотвращения переполнения при работе с большими числами. Асинхронный метод `CalculateFactorialAsync` запускает вычисление в фоновом потоке через `Task.Run`, ожидает завершения с помощью `async`/`await` и выводит результат в консоль. Основной поток вызывает `CalculateFactorialAsync` неблокирующим образом и в цикле выводит индикатор прогресса (символы `*`), пока асинхронная задача не завершит выполнение.

## Задание 2
Реализовано неблокирующее ожидание завершения асинхронной задачи в методе `Main` с помощью оператора `await`.

Точка входа `Main` объявлена как асинхронная (`static async Task Main`). Вместо ручного опроса состояния задачи через `while (!task.IsCompleted)` и блокирующего вызова `task.Wait()` используется оператор `await CalculateFactorialAsync(...)`. Это позволяет приостановить выполнение метода `Main` без блокировки потока операционной системы до окончания вычислений факториала.

## Задание 3
Реализован асинхронный поиск уникальных слов в тексте с параллельной подготовкой данных в основном потоке и синхронной записью результата в файл через `FileStream` и `StreamWriter`.

Метод `ParseAsync` принимает входную строку и в контексте фоновой задачи (`Task.Run`) разделяет её на слова по разделителям (пробел, запятая, точка), формируя коллекцию уникальных слов без повторений с возвратом `Task<IList<string>>`. Пока задача `ParseAsync` выполняется асинхронно, основной поток не блокируется: он запрашивает имя пользователя через консоль и инициализирует `FileStream` и `StreamWriter`. После завершения задачи результат получается с помощью оператора `await`, и итоговые данные (шаблон с именем пользователя, количеством уникальных слов и их перечислением через запятую с точкой в конце) синхронно записываются в файл.
