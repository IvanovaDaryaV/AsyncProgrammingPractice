# Блок 1
## Задание 1
Реализован класс-обертка для работы с классом `Thread`. 

Класс-обертка позволяет выполнять делегат `Action<object>` в потоке, созданном с помощью класса `Thread`. Метод `Start()` вызывает делегат `Action<object>` в отдельном потоке `Thread`. Метод `Wait` блокирует вызвавший его поток до завершения работы делегата.
